DB Desk docs

A native, keyboard-first database browser for macOS, Windows and Linux. Read-only until you say otherwise, credentials encrypted on your machine, one window for every engine you touch.

These pages are generated from the markdown in the repository, so what you read here is what ships with the code. Every page has an “Edit this page” link.

Engines

PostgreSQL, Amazon Redshift, CockroachDB, Greenplum, MySQL, MariaDB, SingleStore, Microsoft SQL Server, ClickHouse, SQLite, DuckDB, Elasticsearch, InfluxDB 3, libSQL, Cloudflare D1, MongoDB, Redis / Valkey, MCP servers, HTTP SQL gateways.

Anything that speaks the PostgreSQL or MySQL protocol works under its own name — Redshift and CockroachDB use the PostgreSQL path, SingleStore the MySQL one — and a generic HTTP SQL gateway or an MCP server covers the rest.
